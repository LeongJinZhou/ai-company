# Plan: right-sized process and enforced skills (for the founder's approval)

Goal: the founder defines a project once; work is cut into slices sized by the work; Tiny tasks lose their planner and founder-proxy call; skills are proposed, seen, checked and proven; the caveman and ponytail rules are spelled out where every worker reads them; the handbook gets shorter. The previous plan (founder-proxy, v1.2.0) is done; see git history and `docs/STATUS.md`.

Tier: Risky. Must-escalate (e) and (f): the founder approves this plan, the merge and the release; founder-proxy is not asked. Target version: 1.3.0. Quoted wording runs from `NEW:` to the end of the line.

Fact check by the planner: both plugins ship a SubagentStart hook (`~/.claude/plugins/cache/ponytail/ponytail/5.3.3/hooks/ponytail-subagent.js`; caveman 4.1.0 tests cover the same event) and the planner run received both rule sets from it. The hook is silent when a mode is off or a matcher excludes the agent, so the Style wording in A.12 is a fallback, not a new channel. The handbook does reach `ecc:*` workers; agent-file lines would not, because the tier builders are `ecc:tdd-guide` and `ecc:doc-updater`.

## F. Risks
- The lead rates a task Tiny and also passes its merge. Counterweights: E.1. Residual: `docs/STATUS.md`, `docs/PLAN.md` and README install commands still count as Tiny (open issue) and now merge with no proxy.
- A `Skills read:` line can be written without reading the skill. It is cheap proof, not strong proof; watch the first 3 tasks.
- A project-wide plan is coarser than a per-task plan; a builder that finds a slice wrong stops, and the plan edit costs a new Gate 1.
- The project skills list is in the project CLAUDE.md, so each change to it is must-escalate (f) and reaches the founder.
- The handbook drops to about 199 lines mostly because rewritten paragraphs are not wrapped. Its size in bytes grows: 17285 today, 19263 with this plan's wording, 19517 after the security fixes, capped at 19600 by test C.5 (about 560 more tokens per session and worker). Tiny saves 2 runs per task.

- founder-proxy and every laptop use the installed handbook: nothing changes until `bash update.sh`.
